**Scope.** MS-00 is the durable ledger core: tables, CAS primitives, and the
hash-chained event log. It owns **no policy** (ownership rules, transition
tables, and provider/receipt policy live in MS-08/MS-01/MS-02). It subsumes
three prior stores: the Factory `RuntimeJournal` (per-run SQLite, WAL), the
Station `Store` (per-station SQLite, JSON blobs), and the DSM `Journal`
(JSONL file) — subsumed into `attempts`, `lease_generations`, and `events`.

**Out of scope (unchanged authorities):** Factory/M4 protected implementation,
verifier authority, receipt serialization/bytes (the ledger stores
`receipt_hash` references only), ownership pins/baselines, Evidence Fabric
schemas, frozen research definitions, multi-host consensus (deferred).

## Normative invariants

1. **I-1 Exactly-one-terminal (storage-enforced).** An `attempts` row reaches at
   most one terminal state, ever. Enforced by a single-column `terminal_state`
   plus a CAS predicate `terminal_state IS NULL` in the same
   `BEGIN IMMEDIATE` transaction as the terminal event append. A watchdog is
   evidence collection only; it is never a correctness mechanism.
2. **I-2 Atomic state+event.** Every state mutation and its event row commit in
   one transaction. No ack before commit, no commit without event append, no
   event append outside the state-mutation transaction.
3. **I-3 Projection reconstruction.** Every read projection is recomputable
   from `events` alone under the deterministic total order
   argmax(`fencing_token`, `writer`, `event_id`). Reconciliation cross-checks
   projection vs tables at startup; disagreement ⇒ abort (fail closed).
4. **I-4 Idempotent admission.** Every mutation carries an idempotency key
   `event_id`. Retry after an ambiguous commit resolves as `duplicate` with the
   original `(seq, hash)`.
5. **I-5 Tri-state integrity.** A lease read yields `current | revoked |
   unknown`; `unknown` is produced only by a failed/unreadable store or an
   exhausted deadline and is never retyped as revoked and never authorizes a
   terminal transition.
6. **I-6 Fail-closed integrity.** Hash-chain verification at open; corruption
   aborts startup; nothing is silently repaired into a PASS-equivalent state.

## Storage engine discipline

- SQLite, `PRAGMA journal_mode=WAL`; writer connections `synchronous=FULL`,
  `foreign_keys=ON`; readers never set lock-sensitive pragmas.
- All mutations in `BEGIN IMMEDIATE`; only transaction *admission* is retryable
  for genuine `SQLITE_BUSY`/`SQLITE_LOCKED` within a bounded budget (writer
  ≤ 1.0 s); admitted body/commit work is never replayed.
- Bounded busy budgets: writer admission ≤ 1.0 s, readers ≤ 5.0 s, lease reads
  ≤ 2.0 s.
- Ledger file/dir operator-private (0o700/0o600, `O_NOFOLLOW`, single hard
  link).
- Genesis digest normalized to `'0'*64`.

## Schema (normative)

### `metadata`
```sql
key TEXT PRIMARY KEY, value TEXT NOT NULL
-- carries control_plane_id, schema_version, created_ns
```

### `events` (append-only hash chain)
```sql
seq       INTEGER PRIMARY KEY AUTOINCREMENT,
event_id  TEXT UNIQUE NOT NULL,        -- idempotency key (MS-08 dedupe)
digest    TEXT UNIQUE NOT NULL,        -- sha256 of canonical record
prev_hash TEXT NOT NULL,               -- '0'*64 genesis
record    TEXT NOT NULL                -- canonical JSON
-- UPDATE/DELETE forbidden by trigger.
```

### `attempts`
```sql
attempt_id     TEXT PRIMARY KEY,
task_id        TEXT NOT NULL,
worker_id      TEXT UNIQUE NOT NULL,   -- never reused
swarm_id       TEXT NOT NULL,
plan_hash      TEXT NOT NULL,          -- [0-9a-f]{64}
contract_hash  TEXT NOT NULL,
contract_json  TEXT NOT NULL,
lease_id       TEXT UNIQUE NOT NULL,
generation     INTEGER NOT NULL,       -- >= 1, monotonic per (plan_hash, task_id)
fencing_token  INTEGER NOT NULL,       -- ledger-issued, monotonic per control plane
workspace      TEXT UNIQUE NOT NULL,
state          TEXT NOT NULL,
revoked        INTEGER NOT NULL DEFAULT 0,
terminal_state TEXT,                   -- NULL until terminal; set exactly once
pid            INTEGER,
created_ns     INTEGER NOT NULL,
updated_ns     INTEGER NOT NULL,
CHECK (state IN ('RESERVED','RUNNING','CANDIDATE','VIOLATED','FAILED',
                 'CANCELLED','AUDIT_FAILED','PURGED')),
CHECK (terminal_state IS NULL OR state = terminal_state)
```

### `lease_generations`
```sql
plan_hash     TEXT NOT NULL,
task_id       TEXT NOT NULL,
generation    INTEGER NOT NULL,
fencing_token INTEGER NOT NULL,
PRIMARY KEY (plan_hash, task_id)
-- well-known row ('__control__','writer') carries the MS-08 writer fencing token
```

### `tasks` (typed guard fields; remaining payload stays JSON)
```sql
project TEXT NOT NULL, id TEXT NOT NULL,
state TEXT NOT NULL,
attempt INTEGER NOT NULL DEFAULT 0,
owner TEXT, lease_id TEXT, fencing_token INTEGER, lease_until REAL,
base_commit TEXT, head_commit TEXT, checks_hash TEXT,
value TEXT NOT NULL,
PRIMARY KEY (project, id),
UNIQUE (project, id, lease_id) -- partial: WHERE lease_id IS NOT NULL
```

### Uniqueness that carries I-1
1. `attempts.attempt_id` PK — one durable row per attempt ever.
2. `attempts.terminal_state` — one column, one write; CAS makes a second
   terminal write impossible even if the writer service misbehaves.
3. Partial unique index for the winning terminal kind:
   ```sql
   CREATE UNIQUE INDEX one_candidate_per_task
     ON attempts(plan_hash, task_id) WHERE terminal_state = 'CANDIDATE';
   ```
4. `events.event_id UNIQUE` + `events.digest UNIQUE` + append-only triggers.

## Transition API (signatures)

```python
class RunLedger:
    def __init__(self, path, *, control_plane_id: str) -> None: ...
        # private-file checks; schema; verify hash chain or raise (I-6).
    def claim(self, contract, *, source_hash, approval, event_id) -> Ack: ...
        # generation CAS + active-attempt uniqueness + identity uniqueness + event append.
    def started(self, attempt_id, pid, *, event_id) -> Ack: ...
        # CAS: state='RESERVED' AND revoked=0.
    def finish(self, attempt_id, state: TerminalState, *,
               fencing_token, event_id, **details) -> Ack: ...
        # CAS per below; raises on rowcount != 1 or stale fencing.
    def revoke(self, attempt_id, *, event_id) -> Ack: ...
    def mark_purged(self, attempt_id, *, event_id) -> Ack: ...
    def lease_read(self, attempt_id, *, deadline=None) -> LeaseRead: ...  # I-5
    def acquire_writer_lease(self, writer_id) -> int: ...  # -> fencing_token
    def submit(self, event: dict) -> Ack: ...
        # validate → dedupe (event_id) → fencing → CAS write → commit → ack.
    def reconcile(self, *, writer_id, fencing_token) -> ReconcileReport: ...
    def verify_chain(self) -> None: ...
```

`Ack = {"seq": int, "hash": str, "disposition": "accepted" | "duplicate",
"fencing_token": int}` (commit-before-ack).
`TerminalState = {'CANDIDATE','VIOLATED','FAILED','CANCELLED','AUDIT_FAILED'}`.

## CAS SQL (normative)

Terminal transition (I-1 carrier), with fencing backstop:
```sql
UPDATE attempts
SET state = :to, terminal_state = :to, updated_ns = :now
WHERE attempt_id = :aid
  AND state IN ('RESERVED','RUNNING','CANDIDATE')
  AND terminal_state IS NULL
  AND (:to != 'CANDIDATE' OR revoked = 0)
  AND :token >= (SELECT fencing_token FROM attempts WHERE attempt_id = :aid);
-- cursor.rowcount MUST equal 1, else ROLLBACK and raise.
-- Event append in the SAME transaction (I-2). Commit-before-ack (I-4).
```

Claim (generation CAS, atomic):
```sql
UPDATE lease_generations
SET generation = :gen, fencing_token = :tok
WHERE plan_hash = :ph AND task_id = :tid AND generation < :gen;
-- rowcount 1 required; 0 rows ⇒ stale claim, fail closed.
```

Writer-lease acquisition (MS-08 fencing token issuance):
```sql
INSERT INTO lease_generations(plan_hash, task_id, generation, fencing_token)
VALUES ('__control__', 'writer', 1, 1)
ON CONFLICT(plan_hash, task_id) DO UPDATE
SET generation = generation + 1, fencing_token = fencing_token + 1
RETURNING fencing_token;
```

## Crash matrix (kill points × typed outcomes)

Typed-outcome vocabulary: `REJECT:JournalError`, `REJECT:ContractError`,
`REJECT:FencingError`, `CRASH:CrashError`, `DISPOSITION:duplicate`,
`RESTART:refused`, `UNKNOWN`, `BLOCKED`. **UNKNOWN/BLOCKED are never PASS.**

| KP | Kill point | Expected typed outcome |
|---|---|---|
| KP-01 | claim with `generation ≤ stored` | `REJECT:JournalError`; 0 rows, 0 events |
| KP-02 | second claim for (P,T) while active | `REJECT:JournalError` |
| KP-03 | duplicate identity insert (worker_id/lease_id/workspace reuse) | `REJECT:JournalError` from IntegrityError; no partial rows |
| KP-04 | `started` on revoked/non-RESERVED; started twice | `REJECT:JournalError`; no spawn event |
| KP-05 | crash in journal write window | `CRASH:CrashError`; reopen; re-submit ⇒ `DISPOSITION:duplicate` with same `(seq,hash)` |
| KP-06 | SIGKILL between COMMIT and caller ack | exactly one terminal event; reopen passes chain check; re-finish ⇒ `REJECT:JournalError` |
| KP-07 | double-finish race (≥100 interleavings) | exactly one winner; loser `REJECT:JournalError` |
| KP-08 | finish(CANDIDATE) vs revoke race | revoke-first ⇒ CANDIDATE rejected; finish-first ⇒ revoke rejected |
| KP-09 | stale/forged/expired lease transition | `REJECT:ContractError` (constant-time compare); no mutation |
| KP-10 | duplicate delivery replay incl. cross-restart | first `accepted`; later `DISPOSITION:duplicate`; one journal record |
| KP-11 | writer restart mid-stream | pending set preserved sorted; re-publish no-op; re-ack False |
| KP-12 | scheduler/worker plane absent at recovery | task ⇒ `blocked`, lease cleared, `worker.expired` event; jobs ⇒ `interrupted`; **no manufactured terminal success** |
| KP-13 | lease read under corruption pressure | `revoked`/`revoked`/`UNKNOWN`/`UNKNOWN`; never retyped |
| KP-14 | watchdog ablation | outcome diff = [] — terminal correctness unchanged |
| KP-15 | `mark_purged` on active attempt | `REJECT:JournalError`; purge-after-terminal once-only |
| KP-16 | event append fails after state CAS | whole transaction rolls back (I-2) |
| KP-17 | hash-chain tamper (flip one event byte) | reopen `RESTART:refused`; no state served |
| KP-18 | crash mid-reconciliation | re-run from Step 0 idempotent; events dedupe by `event_id` |

## Reconciliation (normative order)

Run inside the MS-08 writer before accepting proposals; every step fails closed.

0. **Open & verify** — private-file checks; verify full event hash chain (I-6).
1. **Acquire write lease** — claim CAS; new `fencing_token` fences stale writers.
2. **Rebuild projections** from `events` alone under
   argmax(`fencing_token`, `writer`, `event_id`); cross-check against tables;
   disagreement ⇒ abort (I-3).
3. **Classify interrupted attempts** — rows `RESERVED`/`RUNNING` owned by a
   different control-plane identity ⇒ CAS to terminal `FAILED` with reason
   `interrupted_at_startup`. Crash between reap and finish ⇒ terminal
   `AUDIT_FAILED` with preserved diagnostic (never a manufactured completion).
4. **Stale leases** — `tasks` rows `state='running'` with expired lease or
   (startup ∧ non-`remote:` owner) ⇒ `blocked`, finding "Interrupted work
   requires re-triage. Existing evidence is retained."
5. **In-flight jobs** — `queued`/`running` ⇒ `interrupted`. Jobs never
   auto-resume.
6. **Checkpoint** — append one `control.reconciled` event with per-class counts
   and pre/post head hashes.

Test-hook invariants: no duplicate accepted transition across restart/replay;
projection determinism; exactly-one-terminal preserved by reconciliation CAS;
provenance survives; no retyping of corrupt state into benign values.

## Migration (import-once, verify-always, never rewrite history)

1. **M-a Export** legacy stores in durable order to canonical JSONL with
   per-record digests; genesis-literal mapping (`'GENESIS'` vs `'0'*64`)
   recorded in the migration manifest.
2. **M-b Re-key** `event_id = sha256(store_kind || store_identity || old_seq
   || old_digest)`.
3. **M-c Import** through the same admission path as live writes (`submit`).
4. **M-d Verify** the imported chain and field-by-field projections vs legacy
   dump; mismatch aborts, both stores retained untouched.
5. **M-e Cutover** only after M-d passes for every store; legacy files retained
   read-only as evidence.

Hard rule: never weaken a test to obtain green; retain first-attempt failures;
UNKNOWN/BLOCKED never reported as PASS.
