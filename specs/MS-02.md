## Existence verdicts (from seam gap report @ 3cff6bcd)

- Resolution: **EXISTS** — bounded failover, per-attempt receipts, fail-closed
  unknown provider.
- Registry: **PARTIAL** — registry is programmatic; no declarative manifest or
  manifest hash existed on main at extraction time.
- Gap: **no durable resolution-plan record** — receipts go to the observation
  bus only; bus failures are counted, not fatal. Additive ledger provenance is
  proposed; routing correctness must not depend on it.

## Build-order position

registry + resolver receipts wired into MS-01's event chain, preserving
existing receipt behavior verbatim.

  consumed as-is.
- UNKNOWN/BLOCKED never becomes PASS at this seam.
